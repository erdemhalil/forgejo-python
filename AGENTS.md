# AGENTS.md

pyfj is a generated, fully typed Python client for the Forgejo API.

## Hard rules

- `src/pyfj/_generated/**` is generated: edit `codegen/` and regenerate (`uv run python -m codegen`), committing both sides together.
- `spec/openapi.json` is vendored and never hand-edited. The Spec is the source of truth.
- Documentation is part of the change: update the pages a change affects, and leave `uv run zensical build --strict` green.

## Where to look

- Changing behaviour or the public surface: [docs/development/architecture.md](docs/development/architecture.md) — surface, runtime contract, policies.
- Working on the generator: [docs/development/codegen.md](docs/development/codegen.md) — naming rules, Spec quirk inventory, acceptance criteria.
- Human contributor workflow: [CONTRIBUTING.md](CONTRIBUTING.md).

## Ground rules

- Leave the tree green: ruff, ty, and the tests you can run.
- Generated-code changes ship together with the generator/config change that produced them.
- When runtime hooks drift from the architecture sketch, update the sketch in the same change.

## Commands

- `uv sync` — install dependencies
- `uv run ruff check . && uv run ruff format .` — lint and format
- `uv run ty check` — type check
- `uv run pytest` — unit tests (integration is marker-gated, excluded by default)
- `uv run pytest -m integration` — container tests (Docker required)
- `uv run python -m codegen` — regenerate the surface
- `uv run python scripts/gen_docs.py` — regenerate the API reference pages
- `uv run zensical serve` — preview the docs site
- `uv run zensical build --strict` — verify the docs build

## Documentation

The site is built from `docs/` with Zensical and mkdocstrings-python (`mkdocs.yml`), versioned with mike, and deployed to GitHub Pages: `main` updates the `dev` alias, release tags update `X.Y` and `stable`.

- User pages live at the top level of `docs/`; engineering reference under `docs/development/`.
- The API reference under `docs/reference/**` is generated by `scripts/gen_docs.py` and drift-checked in CI — edit the script, never the pages.
- `CONTRIBUTING.md` is canonical; the generator copies it into the site, so edit the root file.

## Conventions

- Type-annotate everything; prefer `from __future__ import annotations`.
- Library code never prints (ruff T20); raise typed errors instead.
- Generated diffs are reviewed deliberately — a naming-report change is a public API change.
