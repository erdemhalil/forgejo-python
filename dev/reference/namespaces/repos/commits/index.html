ReposCommits

The repos.commits namespace.

list 

list(
    owner: str,
    repo: str,
    *,
    sha: str | None = None,
    path: str | None = None,
    stat: bool | None = None,
    verification: bool | None = None,
    files: bool | None = None,
    not_: str | None = None,
    page: int | None = None,
    limit: int | None = None,
) -> Paginated[Commit]

Get a list of all commits from a repository.

Parameters:

Name Type Description Default
owner str

owner of the repo

 required
repo str

name of the repo

 required
sha str | None

SHA or branch to start listing commits from (usually 'master')

 None
path str | None

filepath of a file/dir

 None
stat bool | None

include diff stats for every commit (disable for speedup, default 'true')

 None
verification bool | None

include verification for every commit (disable for speedup, default 'true')

 None
files bool | None

include a list of affected files for every commit (disable for speedup, default 'true')

 None
not_ str | None

commits that match the given specifier will not be listed.

 None
page int | None

1-based page to start iteration at.

 None
limit int | None

Page size; the instance caps it server-side.

 None

Returns:

Type Description
Paginated[Commit]

CommitList.

Raises:

Type Description
NotFoundError
  1. APINotFound is a not found error response.
ConflictError
  1. EmptyRepository.

Operation ID: repoGetAllCommits
